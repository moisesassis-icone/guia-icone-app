# Guia Ícone, o app

O app do Guia Ícone para iPhone, feito em Expo. Ele abre o Guia de verdade
(guiaicone.com) e acrescenta o que um site não tem: aviso no celular pela
Apple, salvar as artes na galeria, a folha de compartilhar do iPhone e o
login com o Google e com a Apple pela janela segura do sistema.
